# TV MAX

Lecteur vidéo pour Android TV et Google TV.

## Installation
Avec l'application **Downloader** sur la TV, saisis le code fourni ou l'adresse :

https://github.com/Neoss69/tvmax/releases/latest/download/TV-MAX.apk

Compatible avec les TV Android / Google TV et les boîtiers Android (Fire TV, Chromecast avec Google TV…).
Non compatible avec les TV LG et Samsung sans boîtier Android.
